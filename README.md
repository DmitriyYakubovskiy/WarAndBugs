# WarAndBugs

**2D-шутер на выживание с видом сверху, созданный на Unity и C#.**

**Площадка:** VK Play.

Сражайтесь с жуками, собирайте опыт и монеты, открывайте оружие и усиливайте персонажа. Во время забега противники становятся сильнее, появляются новые угрозы и босс, а заработанные монеты позволяют подготовиться к следующей попытке.

> В настройках Unity проект использует название `SpaceBugsSurvivors` и имя компании `TuckaStudio`.

## Игровые возможности

- **Бои с ручным прицеливанием:** движение с клавиатуры, стрельба в направлении курсора, гранаты и рывок.
- **Разные противники:** наземные, летающие и стреляющие жуки, а также босс с собственной логикой поведения.
- **Развитие во время забега:** сбор опыта, повышение уровня и выбор одного из трёх случайно предложенных улучшений. Улучшения влияют на здоровье, урон, скорость движения и темп стрельбы.
- **Магазин и постоянный прогресс:** покупка и улучшение оружия, дронов и дополнительных способностей за игровые монеты; выбор снаряжения для следующего забега.
- **Дроны-помощники:** следуют за игроком и автоматически атакуют противников.
- **Предметы и окружение:** монеты, опыт, лечение, пополнение гранат, разрушаемые ящики и взрывающиеся бочки.
- **Динамика уровня:** случайное размещение объектов, появление противников и событий, рост силы врагов и настройка коэффициента сложности.
- **Интерфейс:** показатели здоровья и опыта, таймер, результаты забега, пауза, настройки звука и переключение между русским и английским языками.
- **Локальные сохранения:** деньги, покупки, выбранное снаряжение и настройки сохраняются между запусками.

## Запуск проекта

1. Установите Unity Hub и редактор **Unity 2022.3.10f1**.
2. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/DmitriyYakubovskiy/WarAndBugs.git
   ```

3. Добавьте каталог `WarAndBugs` в Unity Hub как существующий проект и откройте его указанной версией редактора.
4. Дождитесь импорта ресурсов и восстановления пакетов. При первом открытии потребуется доступ к реестру пакетов Unity.
5. Откройте сцену [`Assets/Scenes/Menu.unity`](Assets/Scenes/Menu.unity) и нажмите **Play**.
6. Начните забег через игровое меню.

В настройках сборки уже включены две сцены: `Menu` с индексом `0` и `Level` с индексом `1`.

### Сборка

1. Установите через Unity Hub модуль сборки для нужной платформы.
2. Откройте **File → Build Settings**.
3. Проверьте порядок сцен: сначала `Menu`, затем `Level`.
4. Выберите платформу, при необходимости нажмите **Switch Platform**, затем **Build**.

## Управление

| Действие | Управление |
| --- | --- |
| Перемещение | `W`, `A`, `S`, `D` или стрелки |
| Прицеливание | Движение мыши |
| Стрельба | Левая кнопка мыши, можно удерживать |
| Граната | Правая кнопка мыши |
| Рывок | `Space` во время движения |
| Открыть или закрыть меню паузы | `Esc` |

Гранаты и рывок становятся доступны после соответствующей покупки в магазине. Использование гранат ограничено их запасом, а рывка — количеством зарядов и временем восстановления.

### Организация кода

Игровая логика построена на компонентах Unity. Общие механики вынесены в базовые классы `Entity`, `Bug`, `Weapon` и `Item`, от которых наследуются конкретные реализации.

- `SpawnSystem` управляет появлением противников, предметов, событий и босса.
- `MapCreatorSystem` размещает объекты в заданных границах карты с проверкой пересечений.
- `ImprovementSystem` формирует выбор улучшений при повышении уровня.
- `BuySystem` и классы `ShopItem` реализуют покупки и работу со снаряжением.
- `SaveSystem` хранит состояние прогресса в `SaveData` и обращается к сохранениям через `ISaveService`.
- `LanguageManager` переключает тексты интерфейса между русским и английским языками.

## Сохранения

Прогресс хранится локально в файле `saves.fun` внутри `Application.persistentDataPath`. Реализация `BinarySaveService` использует бинарную сериализацию через `BinaryFormatter`. Автосохранение выполняется примерно каждые пять секунд игрового времени; сохранение также вызывается при уничтожении компонента `SaveSystem`.

Сохраняются деньги, приобретённые улучшения, выбранные оружие и дрон, коэффициент сложности, язык и громкость. Состояние текущего боя не является сохранением для продолжения забега.

Для Windows при текущих настройках проекта ожидаемый путь:

```text
%USERPROFILE%\AppData\LocalLow\TuckaStudio\SpaceBugsSurvivors\saves.fun
```
